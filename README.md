Smart-Expense-Tracker


Smart Expense Tracker is a Python-based mini project developed to manage daily income and expenses efficiently. The system allows users to add transactions, store records in a CSV file, calculate balance, generate monthly reports, and display expense analysis using graphs.

This project helps users track their spending habits and manage financial records in a simple and organized way.

Features :
- Add Income and Expenses
- Store Transactions in CSV File
- View Transaction History
- Show Balance Summary
- Generate Expense Analysis Chart
- Monthly Expense Report

Technologies Used :
- Python
- CSV File Handling
- Matplotlib
- Datetime Module

How to Run :

1. Install matplotlib

```bash
pip install matplotlib
```

2. Run the program

```bash
python expense_tracker.py
```
